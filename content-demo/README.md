# Demo content (fictional)

Everything in this folder is invented: the person, the projects and the texts.

- Images are generated by `scripts/generate-demo-images.mjs` from `images.json` (abstract compositions, no third-party photos).
- Videos are Blender open movies, embedded from the official Blender channels and credited on each page (CC BY).

To build your own site, add a `content/` folder with the same structure; it replaces this one automatically.
